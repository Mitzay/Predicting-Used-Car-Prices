# Predicting-Used-Car-Prices
## 📘 Project Description

This project focuses on analyzing and predicting used-car prices for the dataset. The goal is to understand how different vehicle attributes such as age, mileage, engine specifications, fuel type, and transmission affect market pricing.

Through exploratory data analysis (EDA), feature engineering, and machine learning modeling, this project aims to build an accurate and interpretable model that can estimate the selling price of a car based on its key characteristics. The analysis also uncovers important trends in the used-car market and highlights which features play the biggest role in determining value.

## 🎯 Objectives

- Perform EDA to understand relationships between car features and price.
- Clean and preprocess data, handling missing values and categorical variables.
- Engineer meaningful features to improve model performance.
- Train and evaluate machine learning models (e.g., Linear Regression, Decision Trees, Random Forest, etc.).
- Compare model performance using metrics like RMSE, MAE, and R².
- Provide actionable insights into the factors influencing used-car pricing.

## 🧠 Techniques Used

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Regression & Tree-Based Modeling
- Parameter Tuning
- Visualization of Trends and Feature Importance

💡 Key Insights

The study reveals how variables such as vehicle age, mileage, brand, fuel type, and engine capacity strongly influence market price. These findings can help dealerships, buyers, and sellers make data-driven decisions when evaluating used cars.
